# car_analysis

## Descripcion

Esta aplicacion nos muestra dos graficos, el primero nos muestra la magnitud del kilometraje de los autos a traves de un grafico de histograma. El segundo grafico nos muestra la relacion que existe entre el precio y el kilometraje de los autos. 

Para utilizar esta aplicacion se puede hacer un clic en cada boton para visualizar el grafico.
